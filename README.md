# Библиотека книг

Лабораторная работа по ООП. Приложение на PyQt6: учёт книг и читателей.

## Запуск

```
pip install PyQt6
python main.py
```

## Что умеет

- вход по логину
- таблица книг, поиск по названию и автору, фильтр (все, свободные, выданные)
- добавить и удалить книгу
- выдать книгу читателю и принять обратно
- сортировка по названию

При закрытии окна в `report.txt` дописывается строка: логин, время входа, время выхода.
