# Библиотека книг

Лабораторная работа по ООП. Приложение на PyQt6: учёт книг и читателей.

## Запуск

Двойной клик по `run.bat` (сам поставит PyQt6, если его нет). Или вручную:

```
pip install PyQt6
python main.py
```

## Что умеет

- вход по логину
- таблица книг, поиск по названию и автору, фильтр (все, свободные, выданные)
- добавить и удалить книгу
- выдать книгу читателю и принять обратно
- сортировка по названию

При закрытии окна в `report.txt` дописывается строка: логин, время входа, время выхода.

## Файлы

- `main.py` - запуск приложения
- `main_window.py` - главное окно
- `dialogs.py` - окна входа и добавления книги
- `widgets.py` - свои виджеты (таблица, кнопки, поля)
- `models.py` - классы Book, Reader, Library, KeyValueMap
- `report.py` - отчёт о сессии
